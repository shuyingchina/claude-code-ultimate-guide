# Claude Code 学习路径

**用 8-11 小时精通 Claude Code。通过可选的深入专题，在你关心的领域钻得更深。**

这是你的结构化入门起点。按顺序完成各模块，然后进入完整指南以获取深度内容。

## 如何使用本路径

### 第 1 步：评估你的水平

**入门者**（Claude Code 第 1 天）：
- 走快速路径：01 → 02 → 03（2 小时）
- 然后跳到完整指南 `Part 1: Quick Start`

**中级者**（使用 Claude Code 1-4 周）：
- 走完整路径：01 → 07（8-11 小时）
- 重点钻研模块 04、05、06、07 以获取深度

**高级者**（使用 Claude Code 1 个月以上）：
- 略读 01-03，深入 04-07
- 跳到指南 Part 9: Advanced Patterns 学习编排

### 第 2 步：选择你的路线

**路线 A：精通基础**（11 小时）
- 按顺序完成模块 01-07
- 完成所有练习
- 每个模块后做 `/lesson-quiz [topic]`
- 以 `/self-assessment comprehensive` 收尾

**路线 B：以 skill 为重点的深入专题**（4-6 小时）
- 模块 01-02（基础）
- 根据你的目标直接跳到模块 04、05 或 06
- 在那一个模块上钻得更深
- 按需链接到高级模式

**路线 C：团队采纳**（5-7 小时）
- 模块 01-02（教授基础）
- 模块 03（团队配置）
- 模块 04-07（团队工作流）
- 在全团队范围运行 `/self-assessment`，识别差距
- 根据差距制定后续培训计划

### 第 3 步：学习并验证

每个模块包含：
- 📖 **阅读**（10-30 分钟）——概念与心智模型
- 🔨 **动手实践**（20-45 分钟）——来自 `examples/` 的真实示例
- 📝 **验证**——用 `/lesson-quiz [topic]` 检验理解

### 第 4 步：钻得更深

完成本路径后，你有以下选择：

**选项 A：深度参考**
→ 跳到 `guide/ultimate-guide.md` 中的相关章节

**选项 B：精通某个领域**
→ 阅读专题指南（例如 `guide/security/`、`guide/ops/`）

**选项 C：用插件搭建**
→ 从 `examples/plugins/` 安装一个插件包

**选项 D：自我评估**
→ 运行 `/self-assessment comprehensive` 以识别剩余差距

## 模块详情

### 模块 01：安装与设置（15 分钟）
**目标：** 让 Claude Code 跑起来并确认其正常工作

- 为你的平台安装（macOS/Linux/Windows）
- 运行你的第一条命令
- 理解 prompt → output 循环
- **练习：** 完成 “First 5 Minutes” 工作流

**难度：** ⭐（入门）
**阅读：** [01-installation.md](01-installation.md)
**然后：** 主指南中的 Part 1: Quick Start

---

### 模块 02：核心循环（45 分钟）
**目标：** 在系统层面理解 Claude Code 的工作方式

- 交互循环（prompt → tool → decision → feedback）
- 上下文与会话
- 计划与思考模式
- **练习：** 用 `/plan` 规划一个真实任务，观察其流程

**难度：** ⭐（入门）
**阅读：** [02-core-loop.md](02-core-loop.md)
**然后：** 主指南中的 Part 2: Core Concepts

---

### 模块 03：记忆与配置（1 小时）
**目标：** 为你的工作流配置 Claude Code

- CLAUDE.md 结构与层级
- 设置优先级（global → project → session）
- 环境变量
- **练习：** 创建你的第一个 CLAUDE.md，自定义设置

**难度：** ⭐⭐（中级）
**阅读：** [03-memory.md](03-memory.md)
**然后：** 主指南中的 Part 3: Memory & Settings

---

### 模块 04：Agents 与专业化（1.5 小时）
**目标：** 为特定任务创建专注的 agents

- 何时使用 agents 而非单一会话
- 工具限制与隔离
- 创建 agents（AGENT.md 格式）
- **练习：** 搭建 2 个 agents（通才 + 专才），并测试它们

**难度：** ⭐⭐（中级）
**阅读：** [04-agents.md](04-agents.md)
**然后：** 主指南中的 Part 4: Agents

---

### 模块 05：Skills 与自动化（1.5 小时）
**目标：** 构建可自动触发的可复用能力

- Skill 生命周期与 frontmatter
- 自动调用模式
- 将脚本与 skills 打包
- **练习：** 创建一个解决重复性问题的 skill

**难度：** ⭐⭐（中级）
**阅读：** [05-skills.md](05-skills.md)
**然后：** 主指南中的 Part 5: Skills

---

### 模块 06：Hooks 与事件（1 小时）
**目标：** 对系统事件实现自动化响应

- Hook 事件与匹配
- 预校验 vs 执行后处理
- 编写安全的 hooks
- **练习：** 向你的配置添加 2 个 hooks（一个 pre，一个 post）

**难度：** ⭐⭐（中级）
**阅读：** [06-hooks.md](06-hooks.md)
**然后：** 主指南中的 Part 7: Hooks

---

### 模块 07：高级模式（2-3 小时）
**目标：** 编排多 agent 工作流

- 多 agent 团队与依赖关系
- 编排模式
- 错误处理与恢复
- **练习：** 为一个真实场景设计一个 3-agent 工作流

**难度：** ⭐⭐⭐（高级）
**阅读：** [07-advanced.md](07-advanced.md)
**然后：** 主指南中的 Part 9: Advanced Patterns

---
